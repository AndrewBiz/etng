# Test corpus provenance

All files are used unchanged, only for compatibility testing.

## Synthetic files (`tests/corpus/synthetic/`) — distributed (MIT)

Generated for this project with Python PIL and tagged with ExifTool 13.55:

| file | origin | license |
| --- | --- | --- |
| `base.jpg` | PIL 13.0.0, 64×48 red square; EXIF/IPTC/XMP written by `exiftool -overwrite_original` | project-owned, MIT |
| `base.tif` | PIL 13.0.0, 64×48 red square | project-owned, MIT |
| `dng_sample.dng` | copy of `base.tif` with `DNGVersion=1.4` and `Make=NIKON CORPORATION` | project-owned, MIT |
| `nef_sample.nef` | copy of `base.tif` with `Make=NIKON CORPORATION`, `Model=NIKON Z 6` | project-owned, MIT |
| `cr2_sample.cr2` | generated by `tests/corpus/make_cr2.py` (CR2 header + shifted TIFF offsets; preview strip filled with `base.jpg`) | project-owned, MIT |
| `truncated.jpg` | first half of `base.jpg`, byte-identical prefix | project-owned, MIT |
| `truncated.heic` | first 1024 bytes of `real/exif.heic` | derived from MIT testdata, MIT |

## Local-only vendor samples — NOT distributed

These files are kept on the development machine for Canon/Nikon/Sony parity
checks but are **not committed** (see `.gitignore`), because the upstream
repository publishes user-contributed photos under
**CC BY-SA 4.0** and has been archived:

| file | origin |
| --- | --- |
| `Canon_40D.jpg`, `Canon_40D_photoshop_import.jpg`, `Nikon_D70.jpg`, `Sony_HDR-HC3.jpg` | `ianare/exif-samples`, https://github.com/ianare/exif-samples (`jpg/`); repository README states user-contributed images are released under Attribution-ShareAlike 4.0 International |

A fresh clone therefore contains 11 corpus files (synthetic + nom-exif). The
local run additionally compares the four vendor JPEGs and their snapshots,
which stay untracked.
