# cli Specification

## Purpose

Командный интерфейс `etng`: приём аргументов в стиле exiftool, обнаружение входных файлов, пакетная обработка, коды возврата и диагностика, пригодные для использования в скриптах и CI.

## Requirements

### Requirement: Exiftool-compatible read flags
Система SHALL принимать флаги `-j`/`-json`, `-G`, `-G1`, `-s`, `-n`, `-q`, `-r`, `-ext`, `-ver` и `--threads N`; неизвестный флаг MUST приводить к ошибке использования до начала обработки файлов.

#### Scenario: Неизвестный флаг
- **WHEN** команда запущена с `--definitely-unknown`
- **THEN** выводится сообщение об использовании, код возврата 2, ни один файл не читается

#### Scenario: Версия
- **WHEN** команда запущена с `-ver`
- **THEN** в stdout выводится объявленная версия совместимости с exiftool, код возврата 0

### Requirement: Input discovery
Система SHALL принимать в качестве аргументов файлы, каталоги и glob-шаблоны, MUST обходить каталоги рекурсивно при `-r` и MUST фильтровать файлы по расширениям при `-ext`.

#### Scenario: Каталог с рекурсией
- **WHEN** указан каталог и флаг `-r`
- **THEN** обрабатываются все файлы поддерживаемых и неподдерживаемых форматов на всех уровнях вложенности

#### Scenario: Фильтр по расширению
- **WHEN** указано `-ext jpg -ext heic` для каталога
- **THEN** обрабатываются только файлы с этими расширениями, регистр не учитывается

### Requirement: Exit codes
Система SHALL кодировать результат: 0 — все файлы прочитаны полностью, 1 — были предупреждения, частичные результаты или неподдерживаемые файлы, 2 — ошибка использования.

#### Scenario: Успешный пакет
- **WHEN** все файлы прочитаны без предупреждений
- **THEN** код возврата 0

#### Scenario: Частичный успех
- **WHEN** один файл из пакета не удалось разобрать
- **THEN** код возврата 1, остальные файлы выведены

### Requirement: Stdout and stderr separation
Система MUST писать результат только в stdout, а предупреждения, прогресс и ошибки — только в stderr, чтобы stdout оставался машинно-читаемым при любых флагах, кроме `-q`.

#### Scenario: Предупреждение и JSON
- **WHEN** при пакетной обработке возникло предупреждение
- **THEN** stdout содержит только JSON, а предупреждение — в stderr

#### Scenario: Тихий режим
- **WHEN** команда запущена с `-q`
- **THEN** некритичные предупреждения подавлены, JSON в stdout не меняется

### Requirement: Parallel batch with deterministic order
Система SHALL обрабатывать файлы пакета параллельно и MUST выдавать записи в порядке, определяемом аргументами и правилами обхода, независимо от числа потоков и порядка завершения задач.

#### Scenario: Разное число потоков
- **WHEN** один и тот же пакет обработан с `--threads 1` и `--threads 8`
- **THEN** последовательность записей в stdout идентична

#### Scenario: Ограничение потоков
- **WHEN** указано `--threads 0`
- **THEN** команда завершается ошибкой использования с кодом 2

### Requirement: Fallback control flags
Система SHALL поддерживать выбор режима fallback флагом `--fallback=auto|never|always` и переменной окружения `ETNG_FALLBACK`, приоритет MUST отдаваться флагу командной строки.

#### Scenario: Fallback отключён
- **WHEN** указано `--fallback=never` и подан неподдерживаемый формат
- **THEN** выводится ошибка по файлу, делегирование exiftool не выполняется

#### Scenario: Переменная окружения
- **WHEN** задано `ETNG_FALLBACK=always` и флаг не указан
- **THEN** все файлы читаются через системный exiftool

### Requirement: Tag selection
Система SHALL поддерживать выбор тегов аргументами `-TAG` и `-GROUP:TAG`, ограничивая вывод указанными тегами; неизвестное имя тега MUST приводить к предупреждению и не исключать остальные выбранные теги.

#### Scenario: Выбор одного тега
- **WHEN** команда запущена с `-j -Make -Model`
- **THEN** в записи, помимо системных полей, присутствуют только `Make` и `Model`

#### Scenario: Неизвестный тег
- **WHEN** указан несуществующий тег `-NoSuchTag`
- **THEN** выводится предупреждение в stderr, остальные выбранные теги выводятся, код возврата 1

### Requirement: Help and usage
Система SHALL выводить краткую справку по `-h`/`--help` с перечнем поддерживаемых флагов, форматов и кодов возврата, и MUST завершаться с кодом 0.

#### Scenario: Справка
- **WHEN** команда запущена с `--help`
- **THEN** справка выводится в stdout, код возврата 0
