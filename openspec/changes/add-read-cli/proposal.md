# Proposal

## Why

ExifTool — де-факто стандарт чтения метаданных, но его Perl-рантайм даёт заметный старт на каждый вызов (~0.1–0.2 с) и не использует параллелизм, что критично при пакетной обработке тысяч файлов в пайплайнах, CI и скриптах. При этом экосистема скриптов завязана на конкретный формат вывода `exiftool -j`, поэтому замена имеет смысл только при побайтовой совместимости этого контракта.

## What Changes

- Новый Rust-проект `etng` (бинарник `etng`) — читалка метаданных изображений с CLI, совместимым по поведению с `exiftool` в режиме `-j`.
- Парсинг без Perl: EXIF/IPTC/XMP/GPS и базовые MakerNotes для JPEG, HEIC/HEIF, TIFF, DNG, CR2, NEF; битые и враждебные файлы не должны ронять процесс.
- JSON-вывод, совместимый с `exiftool -j`: те же имена полей, форматирование значений, порядок записей и полей, поведение `-G`/`-G1`/`-s`.
- Пакетный режим: параллельная обработка по файлам (rayon) с детерминированным порядком вывода, рекурсивный обход каталогов.
- Гибридный fallback: неподдерживаемый формат или непокрытые теги делегируются системному `exiftool`, результат сливается в общий JSON-поток; fallback отключаем флагом и переменной окружения.
- Дифф- и бенчмарк-контур: тестовый корпус с эталонным выводом `exiftool -j`, проверка совпадения тегов и замеры старта/пропускной способности/памяти.
- Write-режим (правка EXIF/XMP) в это изменение **не входит**; архитектура парсеров и писателей разделена так, чтобы write можно было добавить отдельным изменением.
- **BREAKING**: нет — проект новый, внешних контрактов не ломаем.

## Capabilities

### New Capabilities

- `cli`: командный интерфейс `etng` — разбор аргументов в стиле exiftool, обнаружение файлов и каталогов, коды возврата, диагностика в stderr, пакетный и рекурсивный режимы, выбор парсера и управление fallback.
- `json-output`: контракт JSON-вывода, совместимый с `exiftool -j` — структура массива записей, имена и порядок полей, форматирование значений (даты, числа, дроби, размеры), групповые префиксы `-G`/`-G1`, экранирование и кодировка.
- `metadata-read`: извлечение и нормализация метаданных — EXIF, IPTC, XMP, GPS, базовые MakerNotes; поддержка форматов JPEG, HEIC/HEIF, TIFF, DNG, CR2, NEF; устойчивость к битым/враждебным файлам и деградация вместо падения.
- `exiftool-fallback`: гибридное делегирование системному `exiftool` — условия срабатывания, слияние результатов с собственным выводом, отключение, обработка отсутствия exiftool и ошибок делегата.

### Modified Capabilities

Нет — проект с нуля, существующих спек нет.

## Impact

- Новый репозиторий `~/work/etng`, Rust 2024 edition, бинарник `etng` + библиотечный крейт для встраивания.
- Зависимости: `kamadak-exif` (EXIF read), `nom-exif` (HEIF/RAW/MOV-метаданные), `img-parts` (структура JPEG/PNG-сегментов), `serde`/`serde_json`, `rayon`, `memmap2`, `clap` (или собственный парсер exiftool-совместимых флагов), `walkdir`.
- Внешняя зависимость: системный `exiftool` 13.x — эталон для дифф-тестов и цель fallback (не требуется для базового чтения).
- Тестовый корпус: JPEG/HEIC/TIFF/RAW разных вендоров + намеренно битые файлы; эталонные JSON-снимки, сгенерированные `exiftool -j`.
- Не затрагивает существующие проекты пользователя.
