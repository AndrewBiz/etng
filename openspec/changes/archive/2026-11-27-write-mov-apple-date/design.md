# Design

## D1. Поиск значения
Идём `moov` → `meta` → `keys`/`ilst`; находим ключ
`com.apple.quicktime.creationdate` и его `data` value. Смещение считается
абсолютным по исходному буферу.

## D2. Замена
Новое значение: `YYYY-MM-DDTHH:MM:SS` + offset из старой строки.
Offset берётся `rfind` в старой строке (не из даты). Если новая строка
короче — остаток заполняется NUL; если длиннее — ошибка.

## D3. Источник даты
Приоритет `DateTimeOriginal`/`CreateDate` (как для `mvhd`); `ModifyDate`
не трогает Apple creation.

## D4. Отсутствие ключа
Если ключа нет, запись не добавляет его; это отдельный change
(append/rebuild `meta`). `mvhd` обновляется всегда.

## Risks

- Меняется только существующее значение; структура контейнера не двигается.
- Другие Apple-ключи не затрагиваются.
