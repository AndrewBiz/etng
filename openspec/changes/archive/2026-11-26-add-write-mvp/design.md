# Design

## Context

Даты EXIF — ASCII `YYYY:MM:DD HH:MM:SS\0` (20 байт), обычно за пределами
4-байтного inline-поля. Поэтому существующее значение можно перезаписать без
перестройки IFD.

JPEG: EXIF в APP1 (`Exif\0\0`), TIFF начинается после 6 байт заголовка.
TIFF-family: TIFF с начала файла. `DateTimeOriginal`/`CreateDate` — в ExifIFD
(0x8769), `ModifyDate` — в IFD0.

## Decisions

### D1. Только существующие теги
MVP не вставляет записи и не двигает offset'ы. Если тега нет — ошибка, файл
остаётся нетронутым.

### D2. Атомарная замена
Читаем файл, патчим копию, пишем temp в тот же каталог, `sync_all`, копируем
права, `rename`. При ошибке temp удаляется.

### D3. FileModifyDate
Устанавливается после rename через `File::set_modified`; локальная зона, как
у exiftool. Для одной только даты файл не копируется.

### D4. CLI
Присваивания распознаются как `-TAG=VALUE`; при наличии хотя бы одного
присваивания read-пайплайн не запускается. `AllDates` разворачивается в три
EXIF-даты.

## Risks / Trade-offs

- **[Большие RAW]** → копия файла; MVP жертвует скоростью ради атомарности.
- **[HEIC/CR3/MOV]** → не поддержаны, явная ошибка.
- **[XMP/IPTC]** → обновляется только EXIF; это задокументировано.
