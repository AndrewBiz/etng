# Design

## Decisions

### D1. Группировка
Повторные assignments группируются по имени; scalar берёт последнее, массивы —
все значения в порядке CLI.

### D2. XMP
Один `<dc:subject><rdf:Bag><rdf:li>…` и один `<dc:creator><rdf:Seq>…`;
существующие контейнеры заменяются целиком.

### D3. IPTC
Все записи dataset 2:25/2:80 удаляются, затем добавляются по одной на
значение; exiftool показывает список.

### D4. EXIF
Artist — `Alice; Bob` (строка), Copyright — последнее значение.

## Risks / Trade-offs

- **[Порядок]** → сохраняется порядок CLI.
- **[Дубли]** → дубликаты не удаляются.
