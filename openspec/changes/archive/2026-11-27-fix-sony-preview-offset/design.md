# Design

## D1. Когда двигать
Только если длина файла изменилась (`delta != 0`) после sidecar-обновления.

## D2. Где искать
Внутри APP1 Exif находим `SONY DSC`, затем entry `0x2001` типа `undef[7]`.
Value offset (4 байта LE) указывает на preview в MPImage2; обновляем на delta,
если он больше половины старого размера файла (inline/preview внутри APP1 не
трогаем).

## D3. Границы
Sony-специфично; другие MakerNotes с абсолютными preview-offset'ами этим
change не покрываются. При отсутствии MPF/паттерна функция no-op.

## Risks

- Эвристика `old_offset >= old_len/2`; для нестандартных Sony-файлов возможен
  пропуск. Покрыто тестом на реальном файле.
