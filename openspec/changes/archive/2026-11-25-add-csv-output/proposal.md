# Proposal

## Why

Сейчас `etng` умеет только JSON и текстовый вывод. Для сводок, Excel/pandas и пакетной обработки нужен табличный CSV: одна строка на файл, стабильные колонки, предсказуемое экранирование. Одновременно не хватает исключения шумных тегов (`-x`): MakerNotes-простыни и бинарные поля раздувают и CSV, и JSON.

## What Changes

- Добавляется `-csv`/`--csv`: заголовок `SourceFile` + колонки, строка на файл, значения с print-conversion (или машинные при `-n`).
- Колонки при выборе `-TAG`: в порядке аргументов, в каноническом регистре; без выбора — union тегов по всем файлам, по алфавиту.
- `-csv -b` кладёт бинарные значения в ячейку как `base64:<data>`; без `-b` — обычная заглушка `(Binary data N bytes, use -b option to extract)`.
- `-csv -G`/`-G1` даёт колонки с префиксом группы; отсутствующие значения — пустые ячейки.
- Добавляется `-x TAG` / `-x GROUP:TAG` (повторяемый) и `--exclude`: исключение тегов из JSON, текста, `-b` и CSV; исключение сильнее выбора.
- `-csv` имеет приоритет над `-j`, как в exiftool.
- Экранирование CSV: кавычки при запятых, кавычках и переводах строк, удвоение внутренних кавычек.

## Capabilities

### New Capabilities

- `tabular-output`: CSV-режим, состав и порядок колонок, форматирование и экранирование значений.

### Modified Capabilities

- `cli`: фильтр исключения тегов `-x`/`--exclude` и его взаимодействие с выбором тегов.

## Impact

- `crates/etng-core`: `ReadOptions` (`csv`, `exclude`), общий фильтр `wants`, CSV-writer.
- `crates/etng-cli`: разбор `-csv`, `-x`, двухпроходный сбор колонок, режим вывода.
- `crates/etng-tags`: поиск канонического имени тега для заголовков.
- Тесты: CLI (порядок, union, экранирование, base64, `-x`), сравнение с exiftool на корпусе.
- Документация: `README.md`, `docs/divergences.md`.
