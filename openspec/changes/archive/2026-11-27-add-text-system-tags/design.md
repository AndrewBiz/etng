# Design

## D1. Только при selection
Системные поля печатаются, если пользователь явно попросил тег
(`-FileModifyDate`), чтобы не менять текущий text-вывод и снапшоты compare.

## D2. Формат
Тот же, что у тегов: `{name:<32}: {value}`; `-s` не меняет формат, но
убирает лишние группы (у системных полей группы и так нет).

## D3. Порядок
Системные поля до тегов; дубликаты не печатаются, потому что системные поля
не входят в `report.tags`.

## Risks

- Селектор с группой (`System:FileModifyDate`) должен совпадать; используется
  существующий `selection_matches`.
